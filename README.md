# 🎬 7Hub

> Todo filme e série que você já assistiu, registrado.

O **7Hub** é um sistema pessoal de gerenciamento de filmes e séries. Ele foi criado para quem quer manter um registro organizado de tudo o que já assistiu, dar notas aos seus favoritos e descobrir em qual plataforma de streaming um título está disponível atualmente.

---

## ✨ Funcionalidades

* **Busca Inteligente:** Integração direta com a API do **TMDB (The Movie Database)**. Basta buscar pelo nome e o sistema traz automaticamente a capa oficial, sinopse e detalhes.
* **Onde Assistir:** Descubra em tempo real em qual serviço de streaming (Netflix, Max, Prime Video, etc.) o título está disponível no Brasil.
* **Avaliações Pessoais:** Dê sua própria nota para os filmes e séries que você assistiu.
* **Segurança e Privacidade:** Sistema de login com `NextAuth`. Suas senhas são protegidas com hash (`bcrypt`) e seu catálogo é totalmente privado.
* **Interface Moderna:** Design responsivo, animações fluidas e navegação intuitiva construída com Tailwind CSS.
